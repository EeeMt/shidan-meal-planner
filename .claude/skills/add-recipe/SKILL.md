# 添加菜谱

把用户点名的菜通过「联网搜索 → 提供 2~3 种做法变体 → 用户选择 → 按数据结构写入 recipes.js」的流程录进系统。这道菜写进去后会参与一周排菜、购物清单和缺料替代,所以数据质量直接决定排菜体验。

## 数据模型

先读 `recipes.js` 文件头部的字段注释,照抄现有菜谱的风格。每个菜谱对象的结构:

```js
{
  id: 'shuizhu-roupian',   // 菜名拼音,小写、连字符连接,如 yuxiang-rousi
  name: '水煮肉片',
  emoji: '🥩',              // 贴切的食物 emoji
  category: '荤菜',         // 荤菜 / 素菜 / 蛋豆 / 水产 / 汤羹 / 主食 / 凉菜
  difficulty: 2,           // 1 简单 / 2 常规 / 3 复杂
  minutes: 30,             // 总用时(分钟),要与步骤匹配
  servings: 2,             // 基准份量,家常菜多为 2,炖菜大菜可用 3
  tags: ['下饭', '微辣'],   // 快手 / 下饭 / 宴客 / 微辣 / 高蛋白 / 汤 / 凉菜 / 主食 ...
  ingredients: [
    { name: '猪里脊', amount: '300g' },
    { name: '豆芽', amount: '200g' },
    { name: '小葱', amount: '1根', optional: true }  // optional 用于可缺的调料
  ],
  steps: ['步骤一。', '步骤二。', '步骤三。']
}
```

## 流程

### 1. 查重

先在 `recipes.js` 中搜索菜名。若已存在,告诉用户"这道菜已经在库里了",并询问:是想录入不同做法的版本(如饭店版、快手版),还是就此打住。**不要**重复录入同名菜。

### 2. 联网搜索做法

用 WebSearch 搜索中文查询,如「{菜名} 做法」「{菜名} 家常做法」「{菜名} 做法 下厨房」,再用 WebFetch 打开 2~3 个靠谱页面(下厨房、豆果美食、美食杰等),提取主料、辅料及用量、步骤、特点。

- 若网络搜索失败或抓不到内容,**不要停下**:用你自己的常识基于家常做法整理变体,并在展示时明确标注「未搜到网络做法,以下为基于常识整理」,让用户知道来源。
- 对冷门菜,搜索可能只有零星结果——够拼出 2~3 个变体就行,不用追求完美。

### 3. 整理并展示 2~3 种做法变体

按不同流派/侧重整理变体,常见的切法:

- **家常版**:步骤精简(4~6 步)、食材常见易得
- **经典版**(或「川菜版」「饭店版」):更地道的用料与调味
- **快手版**:缩短用时、减少工序

每个变体用 1~2 行说明:特点、用时、辣度。然后把变体列给用户选择。

- 用户已经明确说了偏好(如"家常做法""要辣一点""快手版")→ 不必再问,直接采用对应变体;
- 用户没说明偏好 → 列出变体请用户选一个;
- 无论如何,**选择权在用户**——不要未经选择就写入。

### 4. 默认值(用户未说明口味/做法时)

- **做法**:家常菜做法
- **口味**:家常川菜,辣度**微辣**(tags 含 `'微辣'`)
- 用户明确说「重辣/正常辣度/不辣/饭店做法」等时,按用户要求调整 tags 和做法,微辣只是默认值不是铁律。

### 5. 写入 recipes.js

- 按上面的数据模型构造对象,追加到 `recipes.js` 对应分类的分区注释下方(`// ============ 荤菜 ============` 等)。若没有对应分区(如「凉菜」),追加到放同类的分区——库中凉拌菜都在素菜分区,照此办理。
- `id` 用菜名的拼音、小写、连字符;确认与已有 id 不冲突。
- 用量格式照抄库中风格:`200g`、`2个`、`1勺`、`适量`;步骤用短句,和现有步骤一个语气。
- 写完运行 `node --check recipes.js` 验证语法。
- 用 git diff 检查,只新增、不改动已有菜谱。

### 6. 汇报

告诉用户已录入的菜名、分类、用时、辣度(微辣)、食材数量,以及它参与了哪些功能(排菜/购物清单/缺料替代)。如需多道菜,逐道走完整个流程。

## 注意

- 忠实于搜索到或用户要求的做法,不要为了凑步骤编造离谱的工序;拿不准的用量用「适量」。
- 微辣默认意味着**减少干辣椒用量**——与库中麻婆豆腐、鱼香肉丝的辣度相当。
- 一次对话里连续添加多道菜时,逐道完成「搜索→选择→写入」,不要批量糊弄。
